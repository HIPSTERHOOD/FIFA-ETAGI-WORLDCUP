🏆 ЧМ 2026 по футболу!

Каждый день, с 11 июня, угадывайте победителя до старта игры и получайте призы уже с 4 июля.

📋 Как голосовать:
  1. До начала матча перейдите по ссылке для голосования
  2. Выберите одну из двух команд, которые играют в этот день
  3. Отправьте свой вариант победителя, например: "Бразилия", или укажите точный счёт матча

⚠️ Важно: проголосовать можно только до начала матча, голос после старта не засчитывается.

📊 Подсчет очков и рейтинг

За каждый угаданный итог матча по счёту получите +3 балла, за каждый точный счёт без точного исхода получите +2 балла, за каждую угаданную команду-победителя получите +1 балл. Ежедневно мы публикуем список сотрудников, чья ставка сыграла.

🎁 Без призов вы не останетесь!

Первые призы будут разыграны уже 4 июля по результатам турнирной таблицы.

✅ Все результаты прозрачны, голоса фиксируются по времени.

🏆 ЧМ 2026 по футболу!

Каждый день, с 11 июня, угадывайте победителя до старта игры и получайте призы уже с 4.07.

📋 Как голосовать:

  1. До начала матча перейдите по ссылке для голосования
  2. Выберите одну из двух команд, которые играют в этот день
  3. Отправьте свой вариант, например: "Бразилия"

Важно: проголосовать можно только до начала матча, голос после старта не засчитывается.

📊 Подсчет очков и рейтинг

После каждой игры мы публикуем список сотрудников, чья ставка сыграла. Помните, чем больше дней участвуете, тем больше шансов победить.

🎁 Без призов вы не останетесь!

Первые призы будут разыграны 4 июля по результатам турнирной таблицы. Все результаты прозрачны, голоса фиксируются по времени.

🏅 Система начисления:

  • Угадан исход матча (победа или ничья) — +1 очко
  • Угадан точный счёт — +2 очка
  • Угадан точный счёт + исход — +3 очка

⏰ Важные даты:

  • 11 июня — старт группового этапа
  • 4 июля — первые призы по результатам таблицы
  • 19 июля — финал турнира
